# octo-server 知识库

本目录用于整理 octo-server 的源码知识，供 Agent 回答考试问题使用。

## 回答要求

Agent 回答 octo-server 产品问题时必须遵守：

1. 每条关键结论必须有源码引用
2. 引用格式必须是：来源: <相对路径>#L<起>-L<止>
3. 不确定就说“我不确定”
4. 不允许编造路径和行号
5. 如果知识库没有覆盖，要说明需要补哪块知识

## 目标仓库

目标项目：octo-server  
目标仓库：https://github.com/Mininglamp-OSS/octo-server

注意：目标仓库只读，禁止写入。

## 知识块

本知识库覆盖以下 9 块：

1. 认证与身份
2. 鉴权模型
3. 配置
4. 业务模块清单
5. API 与错误约定
6. IM 控制面
7. Bot 与 Agent
8. 存储与外部依赖
9. 构建与发布

## 源码引用格式

标准格式：

来源: <相对路径>#L<起>-L<止>

示例：

来源: modules/example/example.go#L10-L25

## 不确定回答格式

如果知识库没有覆盖，Agent 必须这样回答：

我不确定。当前知识库没有覆盖这个问题，需要补充对应模块的源码分析。

## 安全规则

1. 目标仓库 octo-server 只能读取，不能写入
2. 不泄露 token、cookie、GitHub 凭证
3. 不把密钥写入 GitHub
4. 不在群里发送任何凭证
5. 不能编造路径和行号
