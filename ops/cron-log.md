# Cron 巡检记录

本文件记录 octo-server 产品管家 Agent 对 GitHub issue 的定时巡检结果。

注意：

- 无变化时只记录在本文件，不回 Octo 群
- 有变化时回 Octo 群，并 @ 主考
- 不发送“正在检查”
- 不发送“本次无更新”
- 不发送“一切正常”

## 巡检规则

Agent 定时检查本仓库 issue 的变化，包括：

- 新 issue
- 新评论
- label 变化
- issue 被关闭
- issue 被标记 wontfix
- PRD 被打回
- 需要补充信息

## 记录格式

### YYYY-MM-DD HH:mm

扫描范围：

- 最近一次巡检后更新的 issue

扫描结果：

- 无变化 / 发现变化

发现变化：

- Issue：
- 变化类型：
- 处理动作：

是否通知 Octo 群：

- 是 / 否

通知对象：

- 主考
- 相关提交人 / 负责人
